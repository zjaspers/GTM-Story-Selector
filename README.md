# GTM Story Selector

A portfolio-safe demonstration of a customer-proof retrieval system for complex enterprise sales.

## What it demonstrates

Customer evidence is most useful when it matches the buyer, business problem, industry, and sales moment. This app lets a seller filter a fictionalized story library by those dimensions and open a concise proof narrative with:

- customer context
- desired outcome
- situation
- proof
- why the story fits
- suggested story angle

## Portfolio safety

All companies, scenarios, and proof points in this repository are fictionalized or generalized for demonstration purposes. This repository does not contain WorkJam customer data, confidential metrics, internal prompts, or proprietary customer materials.

## Run locally

```bash
npm install
npm run dev
```
